# Client app launch page

Static version of the Ramage Law Group client app launch page, for GitHub Pages.

## Settings (near the bottom of index.html)

- `CONFIG.repo`: this repository, as `owner/repo`. Notes are posted here as issues.
- `PAGE_UPDATES`: add an entry at the top each time you change the page.
- `DONE`: mark a checklist step done, for example `"s1-f1": "Joseph, Oct 10"`.

## Change log

- Each note is a GitHub issue. The issue author is the person who wrote it.
- Needs developer action = open issues of type Change request or Question.
- Status: open issue = Open, label `in progress` = In progress, closed as completed = Done, closed as not planned = Won't do.
- Create labels `change-request`, `question`, `comment`, `approval` and `in progress` in the repo so new notes get tagged.
